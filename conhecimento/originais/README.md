# conhecimento/originais/

Cópia literal dos arquivos originais de cada fonte catalogada em `../fontes.md`. Um arquivo (ou subpasta, para fontes com múltiplos arquivos) por fonte, nomeado de forma a deixar claro qual `SRC-xx` ele corresponde, por exemplo `SRC-03-entrevistas-onboarding.pdf` ou `SRC-07-relatorio-nps-q2/`.

Regras:

- O comando `/conhecimento` grava a cópia aqui antes (ou no mesmo passo) de criar o bloco correspondente em `fontes.md`. Uma fonte catalogada sem cópia correspondente aqui é uma inconsistência a ser corrigida.
- Fontes do tipo `desk` (pesquisa externa) não têm arquivo original para copiar; para essas, registre a URL e a data de captura em `fontes.md` e, se possível, salve aqui uma cópia do conteúdo relevante (texto extraído, captura de tela) para preservar a evidência.
- Não edite os arquivos originais depois de salvos. Se uma fonte for atualizada, catalogue-a como uma nova fonte (novo `SRC-xx`) referenciando a anterior, em vez de sobrescrever.

Pasta vazia até que `/conhecimento` seja usado pela primeira vez.
